# Tungsten IDE

A rugged, browser-based development environment built around the Monaco editor.

## Features

- Monaco code editor with syntax highlighting, minimap, bracket guides, and persistent workspace state
- Multi-file explorer, tab management, workspace search, outline, and source-control views
- Live HTML/CSS/JavaScript preview with an isolated iframe
- Built-in sandbox terminal with command history and common project commands
- Command palette, quick file navigation, keyboard shortcuts, resizable panels, and editor preferences
- Responsive, high-density interface designed for long focused sessions

## Development

```bash
npm install
npm run dev
```

Build and lint the project with:

```bash
npm run build
npm run lint
```

The Vite development server binds to `0.0.0.0` for hosted development environments.
